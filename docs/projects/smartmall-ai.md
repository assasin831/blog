# SmartMall AI 智能商城

这个页面用于记录 SmartMall AI 智能商城项目的开发过程。

## 项目目标

构建一个具备商品浏览、下单、余额支付、智能推荐和 AI 导购能力的电商系统。

## 技术栈

- 前端：Vue、Vite、TypeScript
- 后端：Spring Boot、MyBatis Plus
- 数据库：MySQL
- 缓存：本地缓存，后续扩展 Redis 多级缓存
- AI：Spring AI、商品导购 Agent

## 已完成内容

- 前后端基础架构
- 商品列表、商品详情、购物车、订单
- 用户中心、收藏、评论、客服聊天
- 管理员后台
- 余额充值与余额支付
- AI 导购助手的初步 Agent 流程
- 商品搜索相关性优化

## 后续可复盘点

- 高并发压测结果
- 数据库索引设计
- 多级缓存设计
- AI 导购的品牌识别和商品检索链路
- 管理端和用户端 UI 演进
