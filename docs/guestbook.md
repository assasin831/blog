# 留言板

这里是博客的公开留言区。你可以用 GitHub 账号登录后留言，聊学习路线、项目想法、SmartMall AI 的功能建议，或者指出文章里可以继续完善的地方。

这个留言区基于 GitHub Issues 评论组件实现。留言会和当前页面路径关联，方便以后回看和回复。

## 可以聊什么

- 对 SmartMall AI 项目的建议。
- 对博客 UI、内容结构和学习路线的建议。
- Java、Spring Boot、Vue、MySQL、Redis、AI Agent 的学习问题。
- 你希望我后面补充的文章主题。

## 留言方式

在下方 GitHub 留言区点击登录或授权后，就可以直接评论。第一次使用时，GitHub 可能会要求授权评论应用访问公开仓库，这是正常流程。
