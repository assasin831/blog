# 6.24 学习：SmartMall AI 工程化构建与回归检查

今天主要做工程化回归。SmartMall AI 现在模块很多：用户端、管理员端、商品、订单、钱包、AI 导购、缓存、RabbitMQ、秒杀和博客记录，改任何一处都要注意连带影响。

## 检查重点

这次重点看：

- 后端 Maven 编译
- 前端 Vue 类型检查
- 前端生产构建
- 管理员 API 类型是否和后端返回一致
- 秒杀活动和秒杀请求 DTO 是否匹配
- DLQ 审计接口是否能被前端类型正确识别

## 今天修正的细节

秒杀状态返回结构加入了 `campaignId` 后，需要同步修改后端 DTO 转换和前端类型。类似这种字段级变动最容易遗漏，因为它不一定会在逻辑上马上报错，但构建会抓出来。
