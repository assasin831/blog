# 2026-05-30 开始搭建个人博客

## 今天做了什么

- 决定从智能商城项目切换到个人博客项目。
- 了解 GitHub Pages 的基本工作方式。
- 搭建 VitePress 博客骨架。
- 规划每日记录、项目笔记、学习笔记几个栏目。

## 遇到的问题

刚开始容易把博客想得太复杂，例如登录、数据库、后台管理、动态发布等功能都想一次做完。个人博客第一阶段更适合做成静态网站，先把内容写起来。

## 解决思路

采用 VitePress：

- 用 Markdown 写文章。
- 用 GitHub Pages 托管静态页面。
- 用 GitHub Actions 自动构建和发布。
- 先保证写作流程简单，后续再优化视觉和功能。

## 学到了什么

GitHub Pages 本质上是静态网站托管。个人博客如果不需要评论、登录、后台编辑，就可以完全不依赖后端。
