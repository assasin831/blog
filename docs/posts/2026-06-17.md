# 6.17 学习：SmartMall AI DLQ 审计后台展示

昨天补了 DLQ 审计表，今天继续把它显示到管理员后台。

## 页面位置

审计列表放在 `Dead Letter Queue` 面板下面，和死信预览、单条重投、批量重投放在一起。这样操作和记录在同一个上下文里，不需要管理员跳来跳去。

展示字段包括：

- 操作时间
- 操作者
- requested
- requeued
- skipped
- errors
- payload hash / routing key / message

## 操作链路

现在 DLQ 的完整链路是：

```text
查看 DLQ
-> 选择单条或批量重投
-> 二次确认
-> 后端校验 confirm=true
-> 重投到业务 exchange
-> 写入审计记录
-> 后台展示审计历史
```

## 今天的收获

运维功能最怕“能点但不可追踪”。这次加上审计后，DLQ 不再只是一个临时恢复按钮，而是更接近生产系统里的可恢复流程。
