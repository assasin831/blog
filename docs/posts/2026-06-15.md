# 6.15 学习：SmartMall AI 秒杀请求后台分页与运维查询

今天继续补秒杀请求后台。6.11 的版本已经能查看请求，但它更像一个临时列表：只用 `limit` 控制返回数量。

## 为什么要分页

秒杀请求在高并发下增长很快。真实后台不能每次刷新都拿最近几十条，也不能一次拉全量。比较合理的方式是：

```text
page + pageSize + filters
```

所以接口改成返回分页结构：

```json
{
  "items": [],
  "total": 0,
  "page": 1,
  "pageSize": 30,
  "totalPages": 1,
  "hasPrevious": false,
  "hasNext": false
}
```

## 查询条件

秒杀请求支持这些过滤维度：

- `status`
- `userId`
- `productId`
- `requestId`
- `orderNo`

管理员排障时可以直接回答：

- 用户有没有提交成功？
- 请求有没有进入队列？
- 异步订单有没有生成？
- 是否因为库存不足或重复请求失败？
