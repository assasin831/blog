# 6.28 学习：SmartMall AI 秒杀活动、DLQ 审计与 6 月日志补齐

今天把前面几天没发的内容集中补上，也继续完善了 SmartMall AI。相比单纯写日志，更重要的是把 6.11 计划里的几件事真正落到项目里。

## 今天完成的项目内容

### 1. 秒杀活动配置表

新增 `mall_seckill_campaign`，把普通商品和秒杀活动拆开：

```text
product_id
title
campaign_stock
per_user_limit
status
starts_at
ends_at
```

用户参加秒杀时不再只按 `productId` 判断，而是先找到当前商品正在进行的活动，再绑定 `campaignId`。

### 2. 活动库存隔离

Redis 秒杀库存 key 改成活动维度：

```text
smartmall:seckill:campaign:stock:{campaignId}:{productId}
```

用户限购 key 也改成活动维度，避免同一个商品不同场次活动互相影响。

### 3. 管理员秒杀活动后台

管理员后台新增秒杀活动配置区域，支持：

- 创建活动
- 修改活动
- 启用 / 暂停活动
- 按状态和商品筛选
- 分页查看活动列表

这样秒杀不再是写死在代码里的功能，而是具备了基本运营能力。

### 4. 秒杀请求真实分页

管理员秒杀请求列表从 `limit` 查询升级为 `page/pageSize` 分页，支持按状态、用户、商品、requestId 和订单号查询。

### 5. DLQ 重投审计

新增 `mall_dlq_requeue_audit`，记录 DLQ 重投操作：

- 操作者
- 请求数量
- 成功重投数量
- 跳过数量
- 错误数量
- routing key
- payload hash
- 时间

后台也新增了审计列表，让死信恢复过程可追踪。
